Introduction

Carnet de Courses est votre compagnon idéal pour centraliser, analyser et partager vos performances sportives. Que vous soyez coureur débutant ou confirmé, cette application vous aide à suivre votre progression et à atteindre vos objectifs.

Connexion

Compte Personnel

Créez votre compte avec email et mot de passe pour des fonctionnalités complètes :

  • ✓ Sauvegarde cloud sécurisée
  • ✓ Synchronisation multi-appareils
  • ✓ Données privées par défaut
  • ✓ Export et sauvegarde

Interface Principale

Vue d'ensemble : L'interface principale affiche votre tableau de bord avec statistiques, graphiques et liste de courses.

Gestion des Courses

Ajouter une Course

Cliquez sur le bouton + Nouvelle Course en haut du tableau de bord.

Informations disponibles :

• Nom de la course *
• Date *
• Distance (km) *
• Dénivelé (m+)
• Temps de course
• Lieu / Ville
• Photo (JPG, PNG)
• Image automatique (Web/Nom)
• Fichier GPX
• Notes personnelles
• Statut favori
• Partage public
• Accompagnants
Modifier

Cliquez sur l'icône dans une carte de course pour modifier ses informations.

Supprimer

Cliquez sur l'icône et confirmez la suppression définitive.

Spécial : Triathlon & Relais

🏊‍♂️🚴‍♂️🏃‍♂️ Triathlon

En sélectionnant le type "Triathlon", détaillez chaque épreuve :

  • • Natation : Distance (m) et Temps
  • • Vélo : Distance (km), Dénivelé (m) et Temps
  • • Course à pied : Distance (km), Dénivelé (m) et Temps
Courses en Relais

Gérez les courses d'équipe avec précision :

  • • Relais Classique : Utilisez le "Tableau de Relais" pour ajouter chaque segment (distance, dénivelé, temps) individuellement.
  • • Triathlon en Relais : Sélectionnez "En équipe (Relais)" puis choisissez votre discipline (Nageur, Cycliste ou Coureur) pour n'enregistrer que votre partie.

Recherche Avancée

Filtrez vos courses selon plusieurs critères simultanés :

📅 Par Date

Année, mois, période personnalisée

📏 Par Distance

5km, 10km, semi, marathon, ultra

📍 Par Lieu

Ville, région, pays

Wishlist

Planifiez vos courses futures et suivez leur réalisation :

  • Ajoutez des courses à votre liste de souhaits
  • Cochez-les une fois réalisées
  • Suivez votre progression d'objectifs

Interactions Sociales

Encouragez les autres coureurs et créez du lien !

  • Aimer : Cliquez sur le cœur pour féliciter une performance.
  • Voir les "J'aime" : Cliquez sur le compteur de "J'aime" pour voir la liste des personnes qui ont aimé la course.
  • Confidentialité : Vous pouvez masquer le nombre de J'aime sur VOS courses dans les paramètres de compte (visible uniquement par vous).

Paramètres du Compte

Accédez aux paramètres via l'icône dans le bandeau de connexion (ou "Compte" sur mobile). Vous y trouverez :

Profil

Modifiez votre pseudo pour l'affichage public.

Confidentialité

Contrôlez ce que les autres voient sur vos courses publiques :

  • Afficher/Masquer votre pseudo
  • Afficher/Masquer la ville de la course
  • Afficher/Masquer le jour précis (ex: 12 mars)
  • Afficher/Masquer le label "Favori"
  • Masquer le compteur de "J'aime"

Préférences d'interface

Simplifiez votre tableau de bord en affichant uniquement ce dont vous avez besoin :

  • Afficher/Masquer le bouton "Importer mes données"
  • Afficher/Masquer le bouton "Statistiques"

Actions & Aide

  • Tutoriel : Relancez le guide interactif (depuis le tableau de bord uniquement).
  • Sécurité : Réinitialisez votre mot de passe.
